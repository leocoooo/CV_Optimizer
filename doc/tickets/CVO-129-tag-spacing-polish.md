# CVO-129 · Ajustement spacing des tags

Statut: Termine

## Objectif

Ameliorer la lisibilite des tags longs dans la colonne de droite de l'accueil.

## Ce qui a ete fait

- augmentation de l'espacement entre les tags
- augmentation du padding vertical interne
- interlignage plus confortable pour les tags qui passent sur plusieurs lignes

## Resultat attendu

- le texte des tags ne parait plus colle
- les competences et libelles longs restent plus lisibles
