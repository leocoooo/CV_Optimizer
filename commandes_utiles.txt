Lancer docker desktop en fond 

Lancer le conteneur :
docker-compose up -d

Pour supprimer la base :
$ docker exec -it cv-optimizer-db-1 psql -U admin -d job_db -c "DROP TABLE IF EXISTS job_offers CASCADE;"

Pour la recréer :
$ uv run python -m src.database.init_db

Pour vérifier qu'elle a bien été créée 
$ docker exec -it cv-optimizer-db-1 psql -U admin -d job_db -c "\dt"

Pour lire la base :
$ docker exec -i cv-optimizer-db-1 psql -U admin -d job_db -c "SELECT id, title, source FROM job_offers LIMIT 10;"

Pour collecter des offres depuis l'API France travail :
$ uv run python -m src.services.collector 

Webscrapper Welcome to the jungle :
$ uv run python -m src.services.scrappe_wttj

Webscrappé HelloWork :
$ uv run python -m src.services.scrappe_hw

Vectorisation : 
$ uv run python -m src.services.processor

Matcher un texte à une offre :
$ uv run python -m src.services.matcher

Lire un pdf (CV):
$ uv run python -m src.services.cv_reader

Demander une recommandation à un LLM :
$ uv run python -m src.services.llm_advisor 

Lancer le script d'orchestration des features :
- test rapide (2-3 offres par source) :
uv run python -m main "data/CVs/Exemple de CV Data engineer.pdf" "Data Scientist,Data Engineer"
- Collecte complète
uv run python -m main "data/CVs/Exemple de CV Data engineer.pdf" "Data Scientist" full
- Matching uniquement
uv run python -m main "data/CVs/Exemple de CV Data engineer.pdf" "Data Scientist" quick --skip-collect

Executer l'API 
$ uvicorn app.main:app --reload
